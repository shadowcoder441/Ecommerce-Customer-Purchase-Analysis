# E-Commerce Customer Purchase Analysis

## 📌 Overview
This project analyzes customer purchase data from an e-commerce platform using SQL, Excel, and Python. It helps identify purchasing patterns, high-value customers, popular products, and revenue distribution across cities.

---

## 🎯 Problem Statement
E-commerce platforms generate large volumes of transaction data, making it difficult to manually extract meaningful insights. Businesses require data-driven analysis to understand customer behavior and improve decision-making.

---

## 💡 Objectives
- Identify top spending customers  
- Find the most popular products  
- Analyze city-wise revenue distribution  
- Perform brand-wise revenue analysis  

---

## 🧰 Tools & Technologies Used
- MySQL Workbench (SQL queries)  
- Microsoft Excel (Pivot tables & charts)
- Python (Pandas, Matplotlib)
- GitHub (Project hosting)
