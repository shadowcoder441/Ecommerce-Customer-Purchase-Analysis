# E-Commerce Customer Purchase Analysis

## Overview
This project analyzes customer purchase data from an e-commerce platform using SQL, Excel, and Python.

## Objectives
- Identify top spending customers
- Find most popular products
- Analyze city-wise revenue distribution

## Tools Used
- MySQL Workbench
- Microsoft Excel
- Python (Pandas, Matplotlib)

## Key Insights
- Mobile is the most popular product
- Bangalore generates highest revenue
- High-value customers identified for targeted marketing

## Project Files
- ecommerce.csv → Dataset
- analysis.py → Python analysis
- project_report.pdf → Final documentation
